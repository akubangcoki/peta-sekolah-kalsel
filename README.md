# Peta Satuan Pendidikan Kalimantan Selatan

Peta interaktif (Leaflet + OpenStreetMap) 9.799 satuan pendidikan se-Kalimantan Selatan: batas 13 kabupaten/kota, filter, pencarian, dan status ikut TKA.

Sumber data: Data Pokok Pendidikan dan halaman Penetapan Status TKA (diolah). Batas wilayah: GADM 3.6 (tidak resmi, disederhanakan).
